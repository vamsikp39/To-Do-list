# 📝 To-Do List

A simple, responsive, and user-friendly **To-Do List Application** designed to help users manage daily tasks efficiently. The application allows users to add, edit, complete, delete, and filter tasks while tracking overall task statistics.

---

## 📌 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📂 Filter tasks:
  - All Tasks
  - Active Tasks
  - Completed Tasks
- 📊 Real-time task statistics:
  - Total Tasks
  - Completed Tasks
  - Pending Tasks
- 🕒 Timestamp for each task
- 📱 Responsive and clean UI

## 💡 How It Works

1. Enter a task in the input field.
2. Click the **Add** button.
3. Manage tasks using:
   - **Edit**
   - **Complete**
   - **Delete**
4. Use filter buttons to view:
   - All tasks
   - Active tasks
   - Completed tasks
5. Monitor progress using the task summary section.
